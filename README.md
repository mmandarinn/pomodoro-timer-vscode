# Dev Pomodoro Timer

Простой и эффективный Помодоро-таймер для VS Code со встроенной системой жесткой блокировки компиляции и отладки C++ кода во время фазы отдыха. Помогает сфокусироваться на учебе и не нарушать режим перерывов.

## ✨ Функционал

*   **Интерактивный виджет в Status Bar:** Отображение текущего режима (`🔥 Work` / `🌴 Break`), оставшегося времени и кнопок мгновенного управления (`▶` Старт, `⏸` Пауза, `🔄` Сброс, `📊` Статистика).
*   **Блокировка C++ кода:** Во время отдыха плагин перехватывает и жестко завершает любые процессы сборки (`g++`, `clang++`) и сессии отладки (F5), выводя предупреждение с остатком времени.
*   **Гибкая настройка:** Возможность изменять длительность работы, короткого/длинного отдыха и количество циклов до большого перерыва.
*   **Умная статистика:** Подсчет завершенных циклов, чистого времени работы/отдыха, досрочных выходов и пресеченных попыток запустить код за день и за неделю.
*   **Сохранение состояния:** Таймер идеально восстанавливает время и секунды после перезапуска VS Code, даже если он стоял на паузе.

## ⚙️ Настройка интервалов

1. Кликните на текст таймера (`🔥 [Work] 25:00`) в левом нижнем углу строки состояния.
2. Последовательно введите во всплывающие окна нужную длительность:
    * Время работы (по умолчанию: `25` мин)
    * Время короткого отдыха (по умолчанию: `5` мин)
    * Время длинного отдыха (по умолчанию: `15` мин)
    * Количество циклов до длинного отдыха (по умолчанию: `4`)

## 🎮 Управление командами (Ctrl + Shift + P)

Если вам неудобно кликать по кнопкам в Status Bar, вы можете вызвать команды через палитру:
*   `Pomodoro: Start` — запустить отсчет.
*   `Pomodoro: Pause` — поставить на паузу.
*   `Pomodoro: Reset` — полностью сбросить таймер.
*   `Pomodoro: Show Stats` — открыть окно полной статистики.
*   `Pomodoro: Skip Break` — досрочно завершить отдых (доступно только в режиме `Break`, требует модального подтверждения).

## 📦 Установка из VSIX

1. Скачайте файл расширения `*.vsix`(Справа вверху в графе Releases нажать на имя файла и выбрать тот, что с .vsix).
2. В VS Code перейдите во вкладку расширений (`Ctrl + Shift + X`).
3. В правом верхнем углу панели нажмите на три точки `...` и выберите **Install from VSIX...**.
4. Укажите путь к файлу расширения.
